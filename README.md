# Sales Performance Dashboard

Cognevance Technologies - Data Analytics & Business Intelligence (Level 1 - Easy)

An end-to-end analysis of monthly retail sales: data cleaning, analysis, charts, an interactive dashboard with filters, and a written report.

## Folder structure
```
data/         raw_sales_data.csv, cleaned_sales_data.csv
scripts/      generate_dataset.py, 01_clean_data.py, 02_analysis_and_charts.py, 03_build_dashboard.py
dashboard/    sales_dashboard.html (interactive), POWERBI_GUIDE.md (+ .pbix if added)
screenshots/  chart and dashboard images
report/       Project_Report.md, cleaning_log.txt
run_all.py    runs the whole workflow
```

## Workflow
1. **Collect data:** 2,025 retail order lines (2025) generated by `scripts/generate_dataset.py`.
2. **Clean data (pandas):** removed duplicates, filled missing Sales/Segment/City, fixed casing and spaces, parsed dates, added Month/Quarter/Profit Margin.
3. **Analyse:** total sales, profit, margin, top products, category/region performance, monthly trend.
4. **Charts (matplotlib):** line, bar and pie charts saved to `screenshots/`.
5. **Dashboard:** interactive HTML dashboard with filters for Category, Region and Month. A Power BI version can be built with `dashboard/POWERBI_GUIDE.md`.
6. **Report:** insights and recommendations in `report/Project_Report.md`.

## Tools used
Python, pandas, matplotlib, Chart.js, Power BI Desktop, Git/GitHub

## How to run
```bash
pip install -r requirements.txt
python run_all.py
```
Then open `dashboard/sales_dashboard.html` in your browser.

Key findings: Technology drives 66.6% of sales, November is the peak month, Q4 contributes 38.3% of annual sales, and North is the top region. Full details are in the [project report](report/Project_Report.md).
